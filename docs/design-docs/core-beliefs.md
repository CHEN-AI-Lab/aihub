# AIHub 核心理念

## 设计原则
1. **简洁优先** — 不做多余的设计，每个元素都有目的
2. **内容可读性** — 文字清晰、层级分明，移动端阅读体验优先
3. **性能至上** — 最小化 JS 体积，使用静态生成 SSG 优先
4. **智能体友好** — 所有页面有清晰的 HTML 结构和语义化标签

## 质量评分
- SEO: 每个页面必须有 unique title, description, h1
- 性能: Lighthouse > 90
- 可访问性: 所有图片有 alt，表单有 label，颜色对比度达标
- 响应式: 320px-1920px 完美显示
