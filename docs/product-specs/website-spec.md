# AIHub 产品规格文档

## 产品定位
AIHub 是一个**中文 AI 工具导航与评测平台**，帮助中文用户发现、评测和对比 AI 工具。

## 目标用户
- 普通用户：想找好用的 AI 工具但不知从何下手
- 从业者：需要对比和评估不同 AI 工具的性价比
- 工具开发者：希望推广自己的 AI 产品

## 核心功能

### 第一阶段（MVP）

#### 1. 首页
- [ ] Hero 区域：搜索框 + 热门分类快捷入口
- [ ] 精选工具展示（Featured Tools）
- [ ] 最新收录工具
- [ ] 热门分类导航
- [ ] 分类：聊天机器人 / 图像生成 / 视频生成 / 编程助手 / 音频工具 / 办公效率 / 数据分析 / AI 搜索

#### 2. 分类页面
- [ ] 分类标题 + 描述
- [ ] 工具列表（网格/列表视图切换）
- [ ] 筛选：价格（免费/付费/免费+付费）
- [ ] 排序：最新 / 最热 / 评分最高

#### 3. 工具详情页
- [ ] 工具名称、Logo、描述
- [ ] 官网链接 + 推广链接
- [ ] 价格信息（免费/付费/免费增值）
- [ ] 功能介绍
- [ ] 用户评分（1-5星）+ 评论列表
- [ ] 同类工具推荐
- [ ] SEO meta 标签

#### 4. 搜索
- [ ] 全站搜索（工具名 + 描述）
- [ ] 搜索结果页
- [ ] 搜索建议

#### 5. 工具提交
- [ ] 提交表单：名称、描述、URL、分类、Logo URL、价格信息
- [ ] 提交成功提示
- [ ] 管理员审核后可见

#### 6. 评论系统
- [ ] 评分（1-5星）
- [ ] 评论标题 + 正文
- [ ] 优点 + 缺点
- [ ] 评论列表

### 第二阶段（营利功能）

#### 7. 付费收录
- [ ] 付费工具展示（Featured 标签）
- [ ] 首页精选位
- [ ] 分类页置顶

#### 8. 高级会员
- [ ] 去广告
- [ ] 专属内容/报告
- [ ] 优先评论展示

## 非功能需求
- 响应式设计：移动端、平板、桌面
- 首屏加载 < 2s
- SEO 友好：每个页面独立 title/description
- 可访问性：符合 WCAG 2.1 AA 标准
- 暗色模式支持

## 设计参考
- 配色：紫色为主色调（AI 科技感）
- 字体：系统默认字体
- 风格：简洁清爽，Card 式布局
